# Скилл: Поиск и установка плагинов для Ardour на Windows

1. **Сначала проверяй локальные плагины:** вызови `plugin/list_available`, чтобы увидеть всё, что уже доступно в Ardour (встроенные ACE-плагины, LV2, VST2, VST3, CLAP).
2. **Когда просить установку нового плагина:** только если для задачи пользователя действительно не хватает нужного инструмента или эффекта (например: современный wavetable-синт, качественный автотюн/питч-корректор, специфический реверб или драм-сэмплер).
3. **Всегда используй `web_search`** перед рекомендацией, чтобы проверить актуальную официальную ссылку, поддерживаемые форматы (`VST3` / `CLAP` / `LV2` для Windows x64) и бесплатность/лицензию.
4. **Оформляй рекомендацию через инструмент `request_plugin_install`:**
   - Укажи точное название, формат (приоритет `VST3` для Windows), бесплатный/платный статус и зачем он нужен в текущем треке.
   - Укажи стандартный путь установки на Windows: `C:\Program Files\Common Files\VST3` (для VST3) или `C:\Program Files\Common Files\CLAP` (для CLAP).
   - Распиши короткие понятные шаги установки.
   - После того как пользователь нажмёт «Я установил → Пересканировать», вызови `plugin/rescan` и `plugin/list_available`, затем продолжи работу с новым плагином.
5. **Всегда предлагай запасной вариант:** если пользователь решит не ставить внешний плагин, плавно продолжи работу с помощью встроенных плагинов Ardour.
